## Integration boundary

The frontend is still the explicitly labeled scripted demo. The FastAPI game
API, real AI gameplay connection, wallet authentication backend, mint signer,
contracts, and indexer are not implemented. A working gateway does not make the
frontend a live AI game or enable real claims.

Repeat gateway verification after startup:

```bash
python3 scripts/bifrost_setup.py check
python3 scripts/bifrost_setup.py smoke --inference
```

Existing dotenv values were preserved. Configuration backups and pre-QA SQLite
snapshots are in the ignored `data/` directory; no secrets are included here.
