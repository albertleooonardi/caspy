## Findings and coverage limits

1. **P1 — MetaMask is bypassed in local mode.** `wallet.ts` selects unlocked
   Anvil RPC accounts on loopback. Installing/connecting the extension does not
   make Caspy signing use it. A deliberate browser-wallet option, correct local
   chain handling and account/network-change checks need implementation and QA.
2. **P2 — Local image reliability needs improvement.** Attempt one failed and
   attempt two succeeded. Explicit retry preserves the grade and avoids silent
   rerolls, but this does not establish reliable rendering under memory pressure
   or concurrent load. The exact cause of the first failure was not established.
3. **P2 — Intermittent blank Chrome route rendering.** Some navigation/reload
   attempts temporarily showed a blank page despite HTTP 200. Rendering later
   recovered. Console showed MetaMask content-script listener/orphaned-stream
   warnings and an expected unauthenticated `/auth/me` 401; no app JavaScript
   exception was observed. Root cause remains unresolved; do not blame the
   extension conclusively or equate HTTP success with a rendered page.
4. **P2 — Historic judge label consistency remains uncalibrated.** The prior
   report observed exploit-category/flag disagreement. This run's benign win
   cannot establish broad safety benchmark reliability.
5. **P2 — Payout confirmation discrepancy.** User reports were not matched by
   on-chain credit clearance. Investigate the actual submitted transaction hash,
   selected seller account and current market deployment before claiming success.
   Contract/fixture payout tests passed, which does not prove this live payout.
6. **Not covered in Chrome:** cross-workspace researcher buyer request/grant/
   revoke journey (automated fixtures cover it), a freshly played loss, and
   comprehensive mobile/accessibility/security/load testing. No WCAG or
   production-readiness certification is claimed.

Fixed during the wider QA work: privacy text now identifies private Supabase
PostgreSQL storage instead of SQLite. Stale open tabs required refresh after
external ownership changes; no automatic cross-tab synchronization is claimed.
